导入解压后的可话文件夹

文件夹方式适合桌面端 Chrome、Edge 等现代浏览器。浏览器只会读取你主动选择的目录。

操作步骤

  1. 先复制一份原始导出包作为备份，再完整解压到本地磁盘。
  2. 打开可话花园，点击“导入数据”→“打开文件夹”。
  3. 选择解压后包含导出数据的最外层目录，并授权浏览器读取。
  4. 等待索引完成。文件多时请保持页面打开，不要移动原文件。

没有出现内容怎么办

  • 确认没有只选择图片子目录或多套了一层空目录。
  • 确认解压过程完成，没有只生成云盘占位文件。
  • 若浏览器不支持目录选择，改用ZIP 导入。
可话花园只解析现有导出文件，不会补全导出包中本来就缺失的内容。
