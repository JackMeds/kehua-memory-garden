本地处理与数据清除

选择导出包后，文字、照片和视频由页面里的 JavaScript 在当前设备处理，不会上传到可话花园或 GitHub Pages。

IndexedDB 保存什么

为了减少重复解析，浏览器可能在本站的 IndexedDB 中保存本地索引或相关缓存。它属于浏览器站点数据，只对本设备上的该浏览器配置可见。

如何清除

  1. 优先使用应用界面的“清除缓存”功能。
  2. 也可以在浏览器设置中查找 kehua.jackmeds.top 的站点数据并删除。
  3. 清除后，原始导出文件仍留在你自己的磁盘；下次使用需要重新导入。

哪些请求会离开设备

浏览器会请求应用本身的静态 HTML、JavaScript、样式和字体；Cloudflare Web Analytics 会接收匿名页面访问与性能指标。导入的动态正文、照片和视频不是统计内容，不会作为 Analytics 请求发送。

公共或共享设备上使用后，请清除站点数据，并妥善保管原始导出包。
