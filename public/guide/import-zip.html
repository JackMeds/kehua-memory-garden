在手机或电脑上导入 ZIP

ZIP 方式无需先把所有文件解压到一个可选择的目录，尤其适合手机浏览器。

准备 ZIP

  1. 保留原始导出包备份。如果手中是文件夹，可把完整最外层目录压缩为一个 .zip 文件。
  2. 不要只压缩照片目录；描述动态的数据文件和媒体目录都应保留。
  3. 确认设备有足够内存和临时空间。大型视频会增加解析时间。

导入步骤

  1. 打开工具，点击“导入数据”→“打开 ZIP 压缩包”。
  2. 在系统文件选择器中选择对应 ZIP。
  3. 保持页面在前台，等待解析完成后浏览时间线。

移动端提示

系统可能在文件选择器中显示 iCloud、网盘或“下载”目录。最好先把 ZIP 完整下载到设备；云端占位文件可能造成读取失败。若 ZIP 太大，可在电脑端改用文件夹导入。
