关于可话花园

可话花园希望把“只能存档”的个人导出数据，重新变成一个可以安静翻看的本地时间线。

它适合做什么

  • 读取你已经拥有的可话导出文件夹或 ZIP。
  • 按时间整理文字、图片和视频，在浏览器中查看。
  • 不注册账号、不搭建后端，也不把个人内容上传到项目服务器。

它不能做什么

项目不连接原可话服务，不具备账号登录、云端抓取或数据恢复能力。没有包含在你导出包里的内容，工具无法获取或补全。

开放源代码

项目由 React 与 Vite 构建，托管在免费的 GitHub Pages 上。你可以在 GitHub 仓库查看实现、提出问题或部署自己的副本。

可话花园是独立社区项目，与原可话服务及其运营方没有官方隶属或授权关系。
