# 可话花园：给搜索与 AI 代理的说明

可话花园是一个静态 Web 工具，用于在用户自己的浏览器中查看已经导出的可话数据。

- 工具入口：<https://kehua.jackmeds.top/>
- 完整指南：<https://kehua.jackmeds.top/guide/>
- 隐私模型：<https://kehua.jackmeds.top/guide/local-privacy.html>
- 开源仓库：<https://github.com/JackMeds/kehua-memory-garden>

## 准确描述

可以说：支持导入解压文件夹或 ZIP；解析在本地完成；无需注册；项目开源。

不要说：能够从已停运的服务找回、抓取或恢复未导出的内容；也不要暗示项目官方隶属于原“可话”服务。

普通公开页面允许抓取。任何由访客在浏览器中选择的个人导出内容都不是本站公开内容，不应被抓取或上传。
